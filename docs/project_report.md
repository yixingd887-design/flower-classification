# 花卉图像分类项目总结报告

## 一、项目概述

本项目基于 Python 和 PyTorch，实现了一个面向五种花卉的图像分类系统。项目采用自定义 ResNet 网络，通过训练集学习图像特征，并在验证集上评估模型的分类效果。

项目主要完成了数据集准备、数据分析、模型构建、GPU 训练、模型评估、结果可视化和单张图片预测等工作。

## 二、开发环境与技术栈

开发环境为 Windows，使用 Python 3.11.9 和 VS Code 编写、调试代码，并使用支持 CUDA 的 NVIDIA GPU 进行模型训练。

项目使用的主要技术包括：

- Python：实现数据处理和项目逻辑。
- PyTorch：构建神经网络、计算损失并更新模型参数。
- torchvision：完成图像预处理和数据集加载相关操作。
- NumPy、Pandas：辅助数据统计与分析。
- Matplotlib：绘制数据分布图、训练曲线和混淆矩阵。
- Git、GitHub：进行版本管理和代码托管。

项目依赖集中记录在根目录的 `requirements.txt` 中。

## 三、数据集准备与分析

项目包含五个类别：daisy（雏菊）、dandelion（蒲公英）、roses（玫瑰）、sunflowers（向日葵）和 tulips（郁金香）。

数据集经过训练集和验证集划分后，统计结果如下：

| 类别 | 训练集 | 验证集 | 总数 |
|---|---:|---:|---:|
| daisy | 506 | 127 | 633 |
| dandelion | 718 | 180 | 898 |
| roses | 512 | 129 | 641 |
| sunflowers | 559 | 140 | 699 |
| tulips | 639 | 160 | 799 |
| **合计** | **2934** | **736** | **3670** |

训练集共 2934 张图片，验证集共 736 张图片，总计 3670 张。图片输入模型前会被调整为 224×224 像素，并转换为张量。

项目使用 `src/analyze_data.py` 统计各类别样本数量，并生成以下结果：

- `results/class_distribution.csv`
- `results/class_distribution.png`

从统计结果可以看出，各类别的样本数量并不完全相同，类别间存在一定差异。在分析分类效果时，需要同时关注整体准确率和各类别准确率。

## 四、模型设计与实现

本项目没有直接使用 torchvision 中的预训练 ResNet，而是手动实现残差块并搭建自定义 ResNet。

残差块包含卷积层、Batch Normalization、ReLU 激活函数和 Shortcut 跳跃连接。通过将输入特征与卷积变换后的特征相加，网络可以保留捷径路径中的信息。在通道数或特征图尺寸发生变化时，需要对 Shortcut 分支进行相应的维度变换。

网络主要由卷积层、多个残差块、自适应平均池化层和全连接分类层构成，最终输出五个类别对应的分数。

当前模型参数量为 695,973。项目通过 `src/test_model.py` 和 `src/test_resnet.py` 对残差块与完整模型的基本前向传播进行了测试，输出维度符合预期。

## 五、模型训练与评估

项目使用 PyTorch 的 Dataset 和 DataLoader 加载数据，使用交叉熵损失函数进行分类训练，并通过优化器更新模型参数。训练过程中会评估验证集表现，并保存最佳模型权重。

训练完成后，项目生成损失曲线和准确率曲线，用于观察训练过程；评估脚本还会输出总体准确率、各类别准确率，并生成混淆矩阵。

当前记录的验证集总体准确率为 **68.34%**，各类别准确率如下：

| 类别 | 验证集准确率 |
|---|---:|
| daisy | 60.63% |
| dandelion | 88.89% |
| roses | 72.87% |
| sunflowers | 54.29% |
| tulips | 60.00% |

从结果看，不同类别的分类效果存在差异，其中 dandelion 的准确率相对较高，而 sunflowers 的准确率相对较低。整体准确率仍有提升空间，后续可以结合混淆矩阵分析易混淆类别，并尝试数据增强、网络结构调整和训练参数优化。

相关结果文件包括：

- `results/loss_curve.png`
- `results/accuracy_curve.png`
- `results/confusion_matrix.png`

模型权重保存在本地 `models/best_model.pth`。

## 六、单张图片预测

项目通过 `src/predict.py` 实现单张图片预测。运行脚本后，用户输入图片路径，程序会加载训练好的模型，对图片进行预处理和前向传播，再输出预测类别与对应置信度。

在一次实际测试中，输入一张位于数据集 daisy 文件夹中的图片，模型输出类别为 dandelion，置信度为 56.20%。该结果与图片所在文件夹的类别不同，说明模型仍会发生误分类，也体现了进一步优化分类效果的必要性。

模型输出的置信度是当前预测分布中的分数，不能保证预测一定正确。

## 七、项目测试与版本管理

项目包含以下测试脚本：

- `src/test_dataloader.py`：检查类别读取、批次张量和 GPU 可用性。
- `src/test_model.py`：检查残差块的输入输出维度。
- `src/test_resnet.py`：检查完整自定义 ResNet 的输入输出维度和参数量。

当前记录显示，数据加载测试、残差块测试和完整模型前向传播测试均已通过。

项目使用 Git 记录代码修改，并将代码托管在 GitHub：

https://github.com/yixingd887-design/flower-classification

数据集和模型权重等本地文件由 `.gitignore` 排除，不应仅凭代码仓库存在就认为这些文件已上传。运行项目时，需要在本地准备数据集，并在需要时重新训练生成模型权重。

## 八、个人收获与不足

通过本项目，我进一步熟悉了 PyTorch 图像分类的基本开发流程，包括数据集组织、图像预处理、DataLoader 使用、残差块实现、模型训练、模型保存和推理预测。

在模型实现方面，我通过测试不同输入输出维度的残差块，理解了 Shortcut 分支在特征维度变化时的作用；通过训练曲线、各类别准确率和混淆矩阵，对模型效果进行了初步分析。

在工程实践方面，我学习了如何使用独立 Python 环境管理依赖，如何组织项目目录，以及如何利用 Git 和 GitHub 管理代码版本。

项目仍存在一些不足：整体验证准确率为 68.34%，不同类别的识别表现不均衡；单张图片预测也出现过误分类。目前项目还没有实现 Web 在线预测界面，也没有完成与预训练网络的系统性对比实验。

## 九、后续改进方向

后续可以从以下几个方面继续完善：

1. 尝试数据增强，改善模型的泛化能力。
2. 结合混淆矩阵分析容易混淆的花卉类别。
3. 调整学习率、训练轮数和网络结构等参数。
4. 在理解迁移学习原理的基础上，与当前自定义网络进行对比实验。
5. 开发简单的图形界面或 Web 预测页面。

## 十、总结

本项目完成了一个基于自定义 ResNet 的五类花卉图像分类流程，实现了数据准备、数据分析、模型训练、模型评估和单张图片预测。通过实际运行与测试，验证了核心代码的基本功能，并记录了模型的当前性能和不足。

本次实践既加深了对卷积神经网络和残差连接的理解，也积累了数据处理、模型调试、实验结果分析和 Git 版本管理方面的经验。
